## How to use

1. Clone or download this repository
2. Open each folder and follow the instructions in the respective `.md` or source files
3. For MongoDB commands → open `mongosh` or `mongo` shell
4. For Java → compile with `javac` and run with `java` (MongoDB Java Driver required)
5. For PHP → place files in `htdocs` and run via XAMPP
6. For Python → install `pymongo` (`pip install pymongo`)
7. For jQuery & JSON → open the `.html` files directly in a browser (jQuery CDN is used)
