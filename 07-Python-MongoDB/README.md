# Practical 7 – Python and MongoDB

## Prerequisites
```bash
pip install pymongo
```

## How to run
```bash
python insert.py
python update.py
python retrieve.py
python delete.py
```

## Files
- `insert.py`   – Insert a document (interactive)
- `update.py`   – Update age of a document
- `retrieve.py` – Display all documents
- `delete.py`   – Delete a document by name
