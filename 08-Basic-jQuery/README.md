# Practical 8 – Programs on Basic jQuery

Open any `.html` file in a browser. jQuery is loaded from CDN.

## List of Programs

1. `01-Button-Click.html`     – Button click event
2. `02-Selectors.html`        – Class, ID and Element selectors
3. `03-Events.html`           – click, hover, on, off, trigger
4. `04-Show-Hide.html`        – Show and Hide effects
5. `05-Toggle.html`           – Toggle effect
6. `06-Fade.html`             – Fade In / Fade Out
7. `07-FadeToggle.html`       – Fade Toggle
8. `08-Slide.html`            – Slide Up / Slide Down
9. `09-SlideToggle.html`      – Slide Toggle
